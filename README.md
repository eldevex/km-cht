# km-cht — OpenAI-совместимый прокси для Kimi

**OpenAI-совместимый API для Kimi Web Chat через Termux**

Локальный сервер, который превращает браузерную сессию `kimi.ai` в стандартный OpenAI-совместимый API. Работает с Kai 9000, Open WebUI, Chatbox, SillyTavern, OpenAI SDK и другими клиентами.

**Используйте на свой страх и риск.** Проект работает через недокументированный web-API Kimi. Это может нарушать условия использования и привести к блокировке аккаунта. Автор не несёт ответственности за заблокированные аккаунты, неверные ответы модели или любые другие последствия. Используйте одноразовый аккаунт, который не жалко потерять.

---

## ✨ Возможности

* **OpenAI-совместимый API** на `127.0.0.1:5001`
* **Модель** `k2d6-chat` (fallback на неё для любого имени модели)
* **SSE-стриминг** — работает в реальном времени
* **Автообновление токена** — каждые 10 минут + за 5 минут до истечения
* ♻️ **Ротация `refresh_token`** — прокси сам сохраняет новый токен
* **`fs.watch`** — автоматически подхватывает новый auth-файл без перезапуска
* **Автообновление `parent_id`** — диалог продолжается в том же треде Kimi
* **Расширение для снятия дампа** — встроено в репозиторий (`kimi-dumper/`)
* **Минимум зависимостей** — только встроенные модули Node.js

## Установка

### Способ 1: Клонирование репозитория (классический)

```bash
cd ~
git clone https://github.com/eldevex/km-cht.git
cd km-cht
```

### Что дальше — одинаково для обоих способов

**1️⃣ Установите расширение в браузере**

1. Откройте папку `kimi-dumper/` из репозитория — там лежит расширение для снятия дампа.
2. Откройте **Kiwi** или **Titanium Browser**.
3. Включите **Режим разработчика** в разделе расширений.
4. Нажмите **Load unpacked** и выберите папку `kimi-dumper/`.
5. Иконка расширения появится на панели.

**2️⃣ Сделайте дамп auth**

1. Откройте `www.kimi.ai` в том же браузере.
2. Залогиньтесь в аккаунт.
3. Зайдите в чат, где уже есть **хотя бы одно сообщение** (не пустой!).
4. Нажмите иконку расширения → **Очистить буфер**.
5. Отправьте в чат любое сообщение, дождитесь **полного** ответа Kimi.
6. Иконка расширения → **Снять дамп** → файл `kimi-dump-XXXXX.json` сохранится в `~/storage/downloads/`.

**3️⃣ Загрузите дамп в прокси**

```bash
cd ~/km-cht
./update-auth.sh ~/storage/downloads/kimi-dump-XXXXX.json
```

Скрипт распарсит дамп и создаст `kimi-auth.json`. В консоли увидите:

```
✅ kimi-auth.json: kimi-auth.json
   access_token:  eyJhbGciOiJIUzUxMiIs...
   refresh_token: eyJhbGciOiJIUzUxMiIs...
   user_id:       d5u6qpqm52t3748c2810
   chat_id:       1a110ae6-...
   parent_id:     1a110ba5-...
```

**4️⃣ Запустите прокси**

```bash
./start-kimi.sh
```

Вывод:
```
✅ kimi-proxy запущен, PID 2607
Проверка: curl http://localhost:5001/v1/health
Логи: tail -f ./proxy.log
Стоп: pkill -f kimi-proxy.js
```

**5️⃣ Проверьте работу**

```bash
# Health check
curl -s http://localhost:5001/v1/health | python3 -m json.tool

# Тестовый запрос
curl -s http://localhost:5001/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"k2d6-chat","messages":[{"role":"user","content":"привет"}]}' \
  | python3 -m json.tool
```

В health должно быть:
* `token_expired: false`
* `token_seconds_left` — порядка 800–900
* `has_refresh_token: true`
* `chat_id` и `parent_id` заполнены и **разные**

## Управление

```bash
# Запуск
cd ~/km-cht && ./start-kimi.sh

# Остановка
./stop-kimi.sh

# Логи в реальном времени
tail -f ~/km-cht/proxy.log

# Состояние
./status.sh

# Ручной refresh токена
curl -X POST http://localhost:5001/v1/refresh

# Список моделей
curl -s http://localhost:5001/v1/models | python3 -m json.tool

# Проверить процесс
ps aux | grep kimi-proxy
```

## ⚙️ Настройки (переменные окружения)

Все параметры передаются при запуске:

```bash
REFRESH_INTERVAL_MS=600000 \
REFRESH_AHEAD_SEC=300 \
HOST=127.0.0.1 \
nohup node kimi-proxy.js > proxy.log 2>&1 &
```

Переменная | По умолчанию | Описание
---|---|---
`PORT` | `5001` | Порт сервера
`HOST` | `127.0.0.1` | Адрес прослушивания. Поставьте `0.0.0.0`, если подключаетесь с другого устройства
`REFRESH_INTERVAL_MS` | `600000` (10 мин) | Как часто обновлять access-токен
`REFRESH_AHEAD_SEC` | `300` (5 мин) | За сколько секунд до истечения обновлять
`DEBUG` | `1` | Включить подробные логи (`0` — выключить)

## Обновление токена

Access-токен обновляется автоматически. Но `refresh_token` живёт ~30 дней — после этого нужен новый дамп.

**Признаки того, что пора обновить:**

```
[auth] refresh failed
{"error":"invalid_grant","error_description":"The provided authorization grant is invalid"}
```

**Что делать:**

1. Откройте `www.kimi.ai` в браузере, залогиньтесь заново.
2. Снимите свежий дамп через расширение.
3. Выполните:

```bash
cd ~/km-cht
./update-auth.sh ~/storage/downloads/kimi-dump-XXXXX.json
pkill -f kimi-proxy.js; sleep 1
./start-kimi.sh
```

## ❓ Частые проблемы

**Прокси отвечает пустотой (`content: ""`)**

В логе `[kimi] response: content=0`. Причины:
- чат пустой (нет `parent_id`) — откройте непустой чат, отправьте сообщение, снять новый дамп
- токен отозван (`[auth] refresh failed`)
- модель не в списке `AVAILABLE_MODELS` (должна подменяться)

Проверьте: `tail -n 30 ~/km-cht/proxy.log`

**`chat_id missing` / `parent_id == chat_id`**

Дамп снят на пустом чате. Откройте `kimi.ai`, зайдите в непустой чат, отправьте сообщение, дождитесь ответа, снять новый дамп.

**`kimi-auth.json не найден`**

Не прогнан `update-auth.sh`, либо в дампе нет токенов. Снять новый дамп.

**Расширение не устанавливается в браузер**

* Убедитесь, что используете Chromium-браузер с поддержкой расширений (**Kiwi Browser** или **Titanium Browser**) — в обычном Chrome на Android расширения не поддерживаются.
* Включите **Режим разработчика** в настройках расширений.
* При «Load unpacked» выбирайте папку `kimi-dumper/`, а не файл внутри неё.

**Kai не подключается, запросы не доходят**

1. Прокси запущен? `ps aux | grep kimi-proxy`
2. Health отвечает? `curl -s http://127.0.0.1:5001/v1/health`
3. URL в клиенте: `http://127.0.0.1:5001/v1` (не `https`)
4. Смотрите лог: `tail -n 30 ~/km-cht/proxy.log`

**Termux убивается Android'ом**

* Дайте Termux разрешение «Автозапуск» в настройках Android.
* Отключите оптимизацию батареи для Termux.
* Заблокируйте Termux в недавних приложениях, чтобы Android не выгружал его.

## ⚠️ Ограничения

* Прокси работает в **одном чате** — том, что был в дампе. Новый чат → новый дамп.
* Создавать новые чаты без браузера нельзя — Kimi использует кастомный формат xid.
* `refresh_token` живёт ~30 дней. После — нужен новый дамп.
* Прокси не запускается после перезагрузки телефона — нужно запускать вручную.
* Может сломаться при изменениях на стороне Kimi.

---

## Безопасность

* Токены хранятся **только локально** в `kimi-auth.json`. Никуда не отправляются.
* Расширение работает **без** `chrome.debugger`, не открывает внешних соединений.
* Единственное соединение — твой телефон ↔ `kimi.ai`, как в браузере.
* **Никогда не публикуйте** `kimi-auth.json` и `kimi-dump-*.json` — там живые токены вашего аккаунта.
